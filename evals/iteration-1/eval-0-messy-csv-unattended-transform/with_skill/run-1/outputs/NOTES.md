  used. Please confirm the vendor system is US-format; if it is DMY, every date
  in the output is wrong despite matching the sample.

  repair heuristic is conservative (signature match + clean cp1252/latin-1 ->
  UTF-8 round-trip, otherwise pass through), but heuristic repair can in
  principle corrupt legitimate text that looks like mojibake — confirm this is
